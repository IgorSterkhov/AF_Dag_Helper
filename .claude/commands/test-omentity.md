# Test OMEntity Generation

Протестируй утилиту генерации OMEntity на эталонных DAG файлах из папки `Dags samples/`.

## Задача

1. Запусти скрипт тестирования:
   ```bash
   python test_against_samples.py
   ```

2. Проанализируй результаты:
   - Для каждого расхождения определи причину
   - Сгруппируй проблемы по типам

3. Типичные причины расхождений:
   - **API inlets** (`Entity.API`) - утилита не детектит API вызовы, только SQL
   - **Динамический SQL** - SQL формируется в runtime через op_kwargs
   - **Несовпадение серверов** - нужен маппинг в `config/server_mapping.yaml`
   - **Задача пропущена** - уже имеет OMEntity или нет SQL

4. По результатам анализа:
   - Предложи обновления для `config/server_mapping.yaml`
   - Предложи улучшения утилиты если есть системные проблемы
   - Объясни какие расхождения ожидаемы (API, динамический SQL)

## Ожидаемый результат

- Отчёт о тестировании с анализом причин расхождений
- Обновлённый `config/server_mapping.yaml` (если нужно)
- Рекомендации по улучшению утилиты (если есть)
