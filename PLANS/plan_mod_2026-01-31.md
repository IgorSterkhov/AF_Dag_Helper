### Фаза 2: Исправление remote_* таблиц (средняя сложность)

#### 2.1 Изменить FQNBuilder.build_fqn_for_remote()
**Файл:** `generator/fqn_builder.py` (строки 66-78)

**Проблема:** Метод использует `remote_prefix` для lookup сервера, но должен использовать `connection_id` текущего контекста.

**Было:**
```python
def build_fqn_for_remote(self, remote_prefix: str, schema: str, table: str) -> str:
    server = self.get_server_name(remote_prefix)  # Неверно!
    if schema == remote_prefix:
        return f"{server}.{table}"
    return f"{server}.{schema}.{table}"
```

**Станет:**
```python
def build_fqn_for_remote(self, connection_id: str, remote_prefix: str, table: str) -> str:
    """
    Строит FQN для remote_* таблиц.

    Формат: server.remote_prefix.table
    Пример: do-ch13.remote_ch.oof_position_status_v3_rc
    """
    server = self.get_server_name(connection_id)
    return f"{server}.{remote_prefix}.{table}"
```

#### 2.2 Обновить вызовы в OMEntityGenerator
**Файл:** `generator/omentity_generator.py`

Найти все вызовы `build_fqn_for_remote()` и добавить `connection_id`:

```python
# Было:
fqn = self.fqn_builder.build_fqn_for_remote(
    table_ref.remote_prefix, table_ref.schema, table_ref.table)

# Станет:
fqn = self.fqn_builder.build_fqn_for_remote(
    connection_id, table_ref.remote_prefix, table_ref.table)
```

**Влияние:** ~20-25% расхождений

```python
def __init__(self, mapping_file: Optional[str] = None):
    self.mapping: Dict[str, str] = {}
    self.default_behavior = "passthrough"
    self.table_suffixes: List[str] = ["_rc_d", "_rc", "_d"]
    self.suffix_behavior = "keep"

        self.load_mapping(mapping_file)

def load_mapping(self, filepath: str):
    # ... существующий код ...
    self.table_suffixes = config.get('table_suffixes', ["_rc_d", "_rc", "_d"])
    self.suffix_behavior = config.get('suffix_behavior', 'keep')

def normalize_table_name(self, table: str) -> str:
    """Нормализует имя таблицы, удаляя суффиксы если настроено."""
    if self.suffix_behavior != "strip":
        return table
    for suffix in self.table_suffixes:  # Уже отсортированы по длине
        if table.endswith(suffix):
            return table[:-len(suffix)]
    return table

def build_fqn(self, connection_id: str, schema: str, table: str) -> str:
    server = self.get_server_name(connection_id)
    normalized_table = self.normalize_table_name(table)
    return f"{server}.{schema}.{normalized_table}"
```

### Фаза 4: Парсинг ALTER TABLE ATTACH PARTITION (средняя сложность)

#### 4.1 Добавить обработку в SQLAnalyzer
**Файл:** `analyzer/sql_analyzer.py`

В метод `_analyze_statement()` добавить:
```python
# После проверки на INSERT
if isinstance(statement, exp.AlterTable):
    self._handle_alter_table(statement, result)
    return
```

Добавить метод:
```python
def _handle_alter_table(self, statement: exp.AlterTable, result: SQLAnalysisResult):
    """Обрабатывает ALTER TABLE для ATTACH/REPLACE PARTITION."""
    # Целевая таблица
    target_table = statement.this
    if target_table:
        target_ref = self._parse_table_expression(target_table, TableSource.INSERT)
        if target_ref:
            result.outlets.append(target_ref)

    # Ищем FROM в действиях (ATTACH PARTITION ... FROM source)
    for action in statement.actions:
        if hasattr(action, 'find_all'):
            for table in action.find_all(exp.Table):
                source_ref = self._parse_table_expression(table, TableSource.FROM)
                if source_ref:
                    result.inlets.append(source_ref)
```

#### 4.2 Добавить regex fallback
**Файл:** `analyzer/sql_analyzer.py`, метод `_analyze_with_regex()`

```python
# Паттерн для ALTER TABLE ... ATTACH/REPLACE PARTITION ... FROM
alter_pattern = r'ALTER\s+TABLE\s+([a-zA-Z_][a-zA-Z0-9_]*(?:\.[a-zA-Z0-9_]+)?)\s+(?:ATTACH|REPLACE)\s+PARTITION.*?FROM\s+([a-zA-Z_][a-zA-Z0-9_]*(?:\.[a-zA-Z0-9_]+)?)'
for match in re.finditer(alter_pattern, sql, re.IGNORECASE | re.DOTALL):
    target_table = match.group(1)  # -> outlet
    source_table = match.group(2)  # -> inlet
```
