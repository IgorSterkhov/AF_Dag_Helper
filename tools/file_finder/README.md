# File Finder

Утилита для поиска файлов по содержимому с графическим интерфейсом на Tkinter.

## Назначение

Сканирует папку с вложенными подпапками, находит все файлы, содержащие заданную строку, и позволяет скопировать их в отдельную папку.

## Запуск

```bash
python tools/file_finder/app.py
```

Или из корня проекта:
```bash
cd "c:\DevWB\AF Dags Helper"
python -m tools.file_finder.app
```

## Интерфейс

```
┌─────────────────────────────────────────────────────────────┐
│  Поиск файлов по содержимому                               │
├─────────────────────────────────────────────────────────────┤
│  Папка поиска: [____________________] [Обзор...]           │
│  Искать строку: [____________________]                     │
│  Маска файлов: [*.py____________]                          │
│  [☐ Учитывать регистр]                 [Найти]             │
├─────────────────────────────────────────────────────────────┤
│  Найдено: N файлов                                         │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ [☐] path/to/file1.py                                │   │
│  │ [☐] path/to/subdir/file2.py                         │   │
│  └─────────────────────────────────────────────────────┘   │
│  [Выбрать все] [Снять выбор]                               │
├─────────────────────────────────────────────────────────────┤
│  Папка назначения: [________________] [Обзор...]           │
│  [☐] Сохранять структуру папок                             │
│                               [Копировать выбранные]       │
└─────────────────────────────────────────────────────────────┘
```

## Параметры поиска

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| Папка поиска | Корневая папка для рекурсивного сканирования | Текущая директория |
| Искать строку | Текст для поиска в содержимом файлов | — |
| Маска файлов | Glob-паттерн для фильтрации файлов | `*.py` |
| Учитывать регистр | Чувствительность к регистру при поиске | Выключено |

## Параметры копирования

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| Папка назначения | Куда копировать выбранные файлы | — |
| Сохранять структуру папок | Воссоздавать иерархию подпапок | Включено |

## Примеры использования

### Поиск DAG файлов с определённой таблицей

1. Папка поиска: `Dags for test/`
2. Искать строку: `schema.my_table`
3. Маска: `*.py`
4. Нажать "Найти"

### Поиск всех файлов с SQL запросами

1. Папка поиска: корень проекта
2. Искать строку: `SELECT`
3. Маска: `*.py`
4. Снять галочку "Учитывать регистр"

### Копирование с сохранением структуры

При включённой опции "Сохранять структуру папок":
```
Исходный файл:    Dags for test/subdir/dag.py
Папка назначения: C:/backup/
Результат:        C:/backup/subdir/dag.py
```

При выключенной опции:
```
Исходный файл:    Dags for test/subdir/dag.py
Папка назначения: C:/backup/
Результат:        C:/backup/dag.py
```

## Ограничения

- Пропускает бинарные файлы (при ошибке декодирования UTF-8)
- Пропускает файлы без прав доступа
- Поиск выполняется синхронно (интерфейс может "зависнуть" на больших папках)
